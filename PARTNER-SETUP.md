# Setting up your Bill Status Tracker — 3 steps

**Step 1 — Create a free GitHub account** (skip if you already have one)

Go to **github.com**, click **Sign up**, and follow the prompts. Takes about
5 minutes. Think of GitHub like Google Drive, but for code.

**Step 2 — Send your GitHub username to whoever gave you this project**

Once you've signed up, send them your username so they can transfer this
project into your account. You'll get an email from GitHub with an
**Accept** button — click it. Done.

**Step 3 — Open Claude and paste this message**

However you normally use Claude (the Claude app, or ask whoever helps you
with your computer to open one for you), paste this in:

> I have a GitHub repository called `tax-bill-tracker` at
> `github.com/[your username]/tax-bill-tracker`. It's a bill status tracker
> for a state legislature, currently built for Hawai'i, and I need it
> adapted for [your state]'s legislature. Please:
> 1. Turn on GitHub Pages for this repo (Settings -> Pages -> Deploy from a
>    branch -> main -> / (root) -> Save)
> 2. Read the README.md file in the repo -- it has a full adaptation
>    checklist
> 3. Follow that checklist: check whether [your state]'s legislature
>    publishes bill status in a format a computer can read, then update the
>    two files it points to so the tracker understands our state's
>    legislature
> 4. Test it thoroughly before making anything live
> 5. When it's working, explain in plain language what I need to do to add
>    it to our organization's website

The first time, Claude may ask you to approve it connecting to your GitHub
account -- just say yes when that comes up. That's the only technical
decision you'll need to make; everything after is Claude's job.
